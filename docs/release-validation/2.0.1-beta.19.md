# BoardCanvas 2.0.1-beta.19 validation

- Scope: transient top-right action notifications, accurate eraser cursor and center, dashed whole-stroke eraser cursor, and a touch-only mode/size label.
- Node verification: `npm test` passed 191 tests; 2 Windows-only packaging tests were skipped on macOS (193 total). `npm run web:build` and `git diff --check` passed.
- Browser verification: `scripts/check-interaction-feedback.cjs` passed in isolated Chrome at DPR 1 and 2 and camera scales 0.5, 1, and 2. It compares the DOM cursor with the actual erased canvas pixels, verifies undo/redo/page/fit/lock notifications, the dashed cursor, touch label cleanup, automatic dismissal, and absence of page errors. Light/dark board screenshots were inspected locally.
- Regression verification: `scripts/check-touch-history.cjs` passed double/triple tap, tap jitter, pan cancellation, undo/redo after pan, page isolation, and keyboard tool-change cancellation.
- Independent review: in progress before merge; findings and resolution will be recorded here.
- Cursor and notifications are DOM siblings of the canvas world with pointer-events disabled. They do not enter canvas exports or page history.
- Physical Windows touch/stylus hardware and installed upgrade/recovery are not established by browser checks. Signed Windows CI and published asset/feed verification are subsequent deployment gates.
