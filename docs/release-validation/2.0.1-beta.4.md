## 현재 한계

- 2026-10-11 일요일 physical touch sensor와 PPT remote는 pending이다. 따라서 hardware acceptance, published rollback, stable promotion을 완료로 표시하지 않는다.
- Google OAuth Client ID/API/consent와 실제 account login·persistence는 pending이다. 관련 code는 있으나 외부 설정·실계정 검증은 하지 않았다.
- Figma MCP Starter quota가 막혀 latest canvas mutation은 반영하지 못했다. historical 23 SVG는 보존했지만 native Figma components/autolayout은 미완료다.
- public production rollback은 이번 단위에 재실행하지 않았다(이전 local 2 cycles PASS). 실제 v1 EXE는 없고 최초 recovery acknowledgement failure의 원인은 미확정·재현되지 않았다.
- fullscreen measurement는 확인되지 않은 proposal이며 구현하지 않았다. ESP32 pen은 v2 범위 밖이다. CI signing secrets/environment와 full app responsibility mapping도 남아 있다.

이 기록은 beta4 공개 게시와 승인된 설치·검증의 provenance만 기록하며, 모든 최초 요구사항 또는 정식 배포 완료를 뜻하지 않는다.
