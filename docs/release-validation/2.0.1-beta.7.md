Status as of 2026-10-09: the beta.7 Windows x64 installer and signed release manifest are prepared locally from source commit `9e376ea`. Independent release review is pending. Installation, publication, and actual-app updating have not been performed.

## Release notes

- Page fit is available from the toolbar in both pen and pan modes; the duplicate pan-mode fit control is removed.
- The color picker has a visible hue spectrum, a checkerboard-backed opacity control, and a larger live preview. Dragging in the color field updates the selection continuously.
- After upgrading, the app can show the changes for that version once. The notes can be reopened from Settings > About.
