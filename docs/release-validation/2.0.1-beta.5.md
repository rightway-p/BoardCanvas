# BoardCanvas 2.0.1-beta.5 validation

Status as of 2026-10-07: source review PASS and beta.5 published. Installed update and public rollback validation are blocked by Windows automation failure.

## Change scope

- Optional first-run setup wizard, skip without committing drafts, and reopen from Settings / App information.
- Separate current pen and palette settings; palette add/remove, width editing, and shared color picker with transparency inside the picker.
- Pen opacity persists through strokes, restoration, and the shared annotation export renderer. Missing historical opacity defaults to opaque; explicit zero remains zero; eraser remains opaque.
- Extra palette entries use an overflow popup while preserving original input handlers. Palette count limit remains undecided.
- Fullscreen and page-fit controls are directly available on the toolbar. Docked toolbar uses one continuous edge surface and excludes its area from the board.

## Validation boundaries

Root browser checks used isolated `http://127.0.0.1:8775/`, preserving the user's existing preview and installed beta.4.

- Optional skip, final apply, reopen, draft isolation, opacity zero, palette empty-state restoration, and semitransparent stroke reload were exercised.
- Shared color picker Apply preserves parent Settings. Nested picker Escape closes only the picker; subsequent Escape returns from Settings to the wizard. Drive Escape returns to its wizard step.
- Left/right docking at 1280x720 and left docking at 900x570 show all controls with no toolbar scrolling. Compact buttons are 24px and the docked rail is 34px. These dimensions are observed responsive results, not a newly settled product width.
- Browser fullscreen entry/exit and blank-page fit button were exercised. This does not establish installed fullscreen or PDF fit equivalence.
- Physical long-hold, touch sensor, PPT remote, and alpha redraw performance acceptance remain for actual-device testing.
- Google OAuth client configuration is absent; authenticated login, token persistence, and actual Drive PDF download remain unverified.
- Figma synchronization, public rollback, and stable promotion remain separate unfinished work.
