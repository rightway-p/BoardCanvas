# 동작 알림과 지우개 미리보기

사용자의 동작 완료 인지/지우개 위치·크기 가시성 요청. 앞선 자동 진행 지시에 따라 구현·검증·독립 리뷰를 진행한다.

- 판서 영역 오른쪽 위에 한 줄 알림을 약 1.4초 표시한다. 실행 취소/다시 실행, 도구 전환, 페이지 변경, 페이지 맞춤, 전체 지우기, 줌·패닝 잠금 및 중요한 문서 상태에 적용한다.
- 새 알림은 기존 알림을 대체한다. 필기나 지우개 한 획마다 알림을 띄우지 않는다. 포커스/터치 입력을 가로채지 않고 `role=status`로 읽을 수 있게 한다.
- 일반 지우개는 실제 지우기 지름과 일치하는 실선 원, 획 지우개는 탐색 반경에 해당하는 점선 원과 중심점을 표시한다. 두 겹 명암 테두리로 흰색/검은색 배경 모두에서 보이게 한다.
- 마우스/펜 hover와 드래그에 즉시 따라오며, 터치는 접촉 중에만 보인다. 터치에는 손가락 위쪽에 모드/화면상 지름 안내를 추가한다. 위치를 이동시키거나 입력을 지연하지 않는다.
- 실제 지우개 world 지름 × camera scale ÷ pixel ratio를 사용한다. 굵기·도구·줌 변경 시 즉시 갱신한다. 멀티터치의 보조 접촉은 주 입력 위치를 덮어쓰지 않는다.
- 캔버스 이탈, pointercancel, 캡처 상실, 창 비활성화에서 잔상을 지운다. DOM 오버레이로 구현하여 저장/내보내기/실행 취소 기록에 포함되지 않는다.

검증: 알림 타이머/대체/초기 상태, 지우개 좌표·줌·DPR·입력 소유권 단위 테스트. 실제 브라우저에서 표시 위치/크기, 입력 통과, 터치 종료 정리, 밝고 어두운 배경 캡처 확인. 전체 테스트 및 독립 리뷰 후 기존 베타 배포 절차를 따른다.
