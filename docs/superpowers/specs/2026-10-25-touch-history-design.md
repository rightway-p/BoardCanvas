# 두 손가락 탭으로 페이지별 실행 취소 / 다시 실행

사용자가 2026-10-25 대화에서 승인한 동작이다.

- 자동 터치 모드에서 두 손가락으로 두 번 탭하면 현재 페이지의 판서/지우개를 실행 취소한다.
- 두 번째 탭 종료 후 300ms 동안 세 번째 탭이 시작되지 않으면 실행 취소한다. 세 번째 탭이 완료되면 다시 실행만 한 번 한다.
- 각 탭은 두 손가락을 모두 뗄 때 완료한다. 한 번의 탭은 첫 접촉부터 250ms 미만, 접촉별 이동은 12 CSS px 이내로 판정한다. 두 손가락 합류 시간은 기존 설정을 따른다.
- 이동 임계값 초과 시 탭 후보를 영구 취소하고 기존 패닝/줌으로 즉시 이어간다. 접촉이 원점으로 돌아와도 탭으로 재분류하지 않는다. 탭 후보 중에는 카메라를 이동하지 않는다.
- 펜 필기를 지연하지 않는다. 기존 첫 접촉 필기와 합류 판단을 유지한다. 픽셀/획 지우개 입력, 실제 펜 입력은 탭으로 재분류하지 않는다.
- 세 손가락, 긴 누름, pointercancel, 포인터 캡처 상실, 창 비활성화, 페이지/모드/도구 조작은 대기 중인 탭 묶음을 취소한다.
- 페이지 객체를 기준으로 묶음을 격리하고 실행 직전 현재 페이지를 재확인한다. 줌/패닝은 기록에 넣지 않는다.

순수 타이머/접촉 판정은 `js/domain/history-taps.js`, 실제 이벤트 연결은 기존 자동 터치 처리에 둔다. 실제 실행은 기존 `undoStrokeAction` / `redoStrokeAction`을 재사용한다.

검증은 가상 시계 기반 단위 테스트, 실제 입력/기록 함수를 사용하는 통합 테스트, 브라우저 포인터 이벤트 검사, 전체 테스트와 웹 빌드, 독립 코드 리뷰 순서로 수행한다. 물리 터치 하드웨어 검증 여부는 별도로 기록한다. 검증/리뷰 후 베타 게시까지 사용자 승인됨.
